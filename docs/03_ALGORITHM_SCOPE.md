# Algorithm Scope v0.1

## 本项目处理流程

目标流程：

1. 读取 BIDMC CSV。
2. 通过 `strip()` 方式归一化列名。
3. 读取时间戳 `Time [s]`、ECG 导联 `II`、PPG `PLETH`。
4. 校验时间戳采样间隔是否符合 125Hz。
5. ECG、PPG、时间戳同步降采样到 50Hz。
6. 在 50Hz ECG 上检测 R 峰。
7. 根据相邻 R 峰计算 RR，单位 ms。
8. 导出逐采样点 CSV。

## 当前算法范围

- 输入：单个 BIDMC CSV。
- ECG 输入列：`II`，匹配时允许原始列名为 ` II`。
- PPG 输入列：`PLETH`，匹配时允许原始列名为 ` PLETH`。
- 时间戳输入列：`Time [s]`。
- 原始采样率：125Hz。
- 目标采样率：50Hz。
- 输出：R 峰标记 + RR。
- 不输出：HR、HRV、医学诊断结论。

## 异常处理边界

本阶段只做基础处理：

1. 字段缺失：报错。
2. 时间戳明显异常：给 warning 或报错，具体由后续里程碑细化。
3. RR 明显异常：后续可标记 invalid，但当前 M1 不实现。
4. 不做复杂心律异常分类。

## 质量验证边界

当前没有参考 R 峰标注，因此只做：

1. smoke test；
2. 可视化人工检查；
3. R 峰数量合理性；
4. RR 范围合理性；
5. 输出字段完整性。
